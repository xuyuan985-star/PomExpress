# 目录布局：项目本体 / 工作副产物

> 目的：**物理分离**「项目本体」与「工作副产物」。
> 清理残留时只需处理**一个**目录，不必在项目里逐个辨认。

---

## 一、盘上布局

```
<父目录>\
├── PomExpress\              ← ① 项目本体（= 仓库）
│   ├── app\ gui\ runtime\ ingest\ config\ security\   代码
│   ├── knowledge\ assets\                             数据与素材
│   ├── docs\ README.md CLAUDE.md CHANGELOG.md VERSION  文档
│   ├── requirements.txt PomExpress.spec start_pom_express.bat  配置与入口
│   └── .git\ .github\ .gitignore .env.example
│
└── PomExpress_local\        ← ② 工作副产物区（不在仓库内）
    ├── m7_venv\             Python 运行环境（约 1.45 GB）
    ├── knowledge\           knowledge 的可写副本
    │                        （你录的轨迹、自定义地图都在这儿）
    ├── logs\                运行日志
    ├── state\               完成状态
    ├── settings\            GUI 设置回退后端
    ├── reports\ failure_reports\
    ├── runtime.db           运行时数据库
    ├── ingest\              截图等中间产物
    └── .env                 本机配置（密钥）
```

打包产物另放：`<父目录>\_build\PomExpress\`（不落在项目内）。

**判据**：`git ls-files` 能列出的 → 项目本体；列不出的 → 副产物。

## 二、代码侧如何实现

`config/settings.py` 定义两个根：

| 常量 | 源码模式 | 打包模式 | 放什么 |
|---|---|---|---|
| `RESOURCE_ROOT` | 项目本体 | `sys._MEIPASS`（退出即删） | 只读资源：`knowledge/` `assets/` `VERSION` |
| `DATA_ROOT` | 同级 `PomExpress_local`（不存在则回退项目根） | exe 同级 | 可写数据 |

**规则：写数据一律用 `data_path()` / `DATA_ROOT`，不要用 `ROOT`。**
`ROOT` 的语义是 `RESOURCE_ROOT`——打包后它指向临时解包目录，写进去的数据退出即丢。

副产物区定位规则：

```python
# 约定：项目根的同级目录 <项目目录名>_local
_local = Path("..") / "<项目目录名>_local"
DATA_ROOT = _local if _local.is_dir() else <项目根>    # 不存在则回退旧行为
```

可用环境变量 `POMEXPRESS_LOCAL_DIR` 指向别处。
**把副产物区整个删掉，代码会自动退回「写入项目根」的旧行为，不会崩。**

`knowledge/` 特殊处理：整体是只读资源，但 `trajectories/` 与
`guides/maps/08_custom/` 需要可写，故**首次运行把整份 `knowledge/` 播种到
`DATA_ROOT` 一份可写副本**，之后一律用该副本。

## 三、读写位置对照

| 组件 | 读（项目本体） | 写（副产物区） |
|---|---|---|
| `app/__main__.py` | — | `logs/crash_trace.log`、`exit_trace.log`、`startup_error.log` |
| `app/launcher.py` | `knowledge/` | `logs/` |
| `app/preflight.py` | `knowledge/`、运行环境 | `logs/startup_error.log` |
| `gui/run.py` | `knowledge/` | `logs/*.log`、`dump/` |
| `gui/main_window.py` | `knowledge/source/...` | `logs/`、`settings/gui_settings.ini` |
| `gui/sound.py`、`gui/pages/settings.py` | — | `settings/gui_settings.ini` |
| `runtime/chest_state.py` | — | `state/` |
| `runtime/input/recorder.py` | `knowledge/` | `knowledge/trajectories/` |
| `knowledge/guides_loader.py` | `knowledge/guides/maps/` | 同上 + `08_custom/` |
| `runtime/platform/windows/game_launcher.py` | `assets/templates/click_enter.png`、`.env` | — |

> `.env` 放副产物区（含本机密钥、本就不入库），避免在项目本体里误删/误提交。
> 代码查找顺序：副产物区 → 项目本体。

## 四、清理残留

**只需删副产物区里的东西**，项目本体不用碰：

```powershell
Get-ChildItem "<父目录>\PomExpress_local" -Force |
    ForEach-Object { $s=(Get-ChildItem $_.FullName -Recurse -File -EA SilentlyContinue |
                         Measure-Object Length -Sum).Sum
                     "{0,-22} {1,9:N1} MB" -f $_.Name, ($s/1MB) }
```

| 想清什么 | 删什么 | 后果 |
|---|---|---|
| 运行日志/截图 | `logs\` `ingest\` | 无（自动重建） |
| 任务完成状态 | `state\` + `runtime.db` | 丢失「哪些宝箱已开」的记录 |
| 失败记录 | `failure_reports\` `reports\` | 丢失排障线索 |
| **全部重置** | 整个 `PomExpress_local\` | 需重跑启动脚本重建环境（1–3 分钟装依赖）；**录制的轨迹与自定义地图也会没** |

## 五、⛔ 不要删

| 项 | 原因 |
|---|---|
| `PomExpress\knowledge\` | 地图集与知识包（**项目资产**，入库） |
| `PomExpress\assets\` | 地图 模板素材 368 张 + 应用图标 |
| `PomExpress\.pytest_cache\` | pytest 缺它会往仓库根留**删不掉的空壳** |
| `PomExpress_local\m7_venv\` | 唯一运行环境（可随整个副产物区一起重建，但别单独删） |
| `PomExpress_local\knowledge\` | 你录的轨迹与自定义地图只在这里，**删了不可恢复**（不在 git 里） |
| `PomExpress_local\.env` | 本机配置与密钥 |

## 六、常见疑问

**Q：`m7_venv` 是别的项目留下的环境吗？**
不是。名字是历史遗留，它是**本项目自己的运行环境**
（Python 3.14 + PySide6/opencv/rapidocr 等）。可直接调 `Scripts\python.exe`，
整体搬移也不会坏。

**Q：为什么 `.env` 在副产物区？**
它含本机密钥、本就不入库；放副产物区可避免在项目本体里误删/误提交。
代码查找顺序是副产物区 → 项目本体，旧位置仍可用。
